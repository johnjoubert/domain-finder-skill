# Candidate generation and taste ranking

## Candidate families

Generate independent batches so one idea does not dominate:

1. **Product object + outcome** — what users create plus what improves.
2. **Product object + navigation** — course, bearing, heading, helm, north, path.
3. **Product object + motion** — ascent, lift, glide, stride, momentum.
4. **Signal or voice language** — signal, voice, cadence, reach, response.
5. **Guidance language** — coach, guide, cue, nudge, mentor.
6. **Coined blends** — short pronounceable fusions with an explainable semantic root.
7. **Favorite + modifier** — retain a strong brand with a clean phrase domain such as `<brand>coach.com`.

Filter out hard-to-spell sounds, accidental negative meanings, misleading categories, famous marks in the same category, overlong compounds, and names whose explanation does all the work.

## Hearing test

For every finalist, ask:

1. If someone hears it once, can they type the domain?
2. If someone sees it once, can they pronounce it?
3. Does lowercase treatment preserve word boundaries?
4. Does it sound credible in “I use ___” and “Go to ___.com”?

## Exact brand versus modifier domain

### Exact-match brand

The product is `Example Brand`; the domain is `example-brand.com`.

Advantage: clean recall. Downside: surviving exact compounds may be descriptive or less distinctive.

### Brand-first with modifier

The product is `Example`; the domain is `example-app.com`.

Advantage: preserves the shorter brand. Downside: the spoken domain differs from the bare brand and must remain honest and easy.

Present these as different strategies rather than pretending a modifier domain exactly matches the bare brand.

## Shortlist format

For each finalist provide:

- **Name** — `exactdomain.com`
- Product and emotional fit
- Identity or icon fit, if relevant
- Principal downside or ambiguity
- Narrow, timestamped registry evidence
